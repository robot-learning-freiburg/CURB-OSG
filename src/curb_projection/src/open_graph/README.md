# OpenGraph Perception
This code is adapted from [OpenGraph](https://github.com/BIT-DYN/OpenGraph) by Deng et al. (2024).

Specifically, we adapt their perception pipeline using:
- [Tag2Text](https://github.com/xinyu1205/recognize-anything)
- [Grounding DINO](https://github.com/IDEA-Research/Grounded-Segment-Anything)
- [TAP](https://github.com/baaivision/tokenize-anything)
